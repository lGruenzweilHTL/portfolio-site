vektorgrid

A self-hosted voice assistant, built as a distributed system: edge relays capture speech, a central orchestrator runs the model pipeline, and a phone app approves anything risky.
GitHub ↗
Architecture
drag to pan the full diagram →

Everything routes through Origin; no two nodes talk directly. A Relay catches the wake-word and streams audio to Origin, which drives the Scalar pipeline in order (STT → intent router → expert LLM → TTS), calling each worker and collecting its result before the next. The spoken reply returns through the Relay. If the model requests a risky tool call, Origin pauses and asks Gate to approve it with biometrics. Gate also runs standalone: it polls Origin for metrics and has a Relay built in, so you can talk to the system from your phone.

About

I'm Lukas, a student in Austria. Backend systems and AI tooling are most of what I do, plus games, and every so often a Raspberry Pi bolted to a Lego robot for a competition.

Most of my projects started because something annoyed me. I built SceneForge AI because setting up scenes by hand is tedious, and the serial protocol behind RoboDucks because there was no clean way to drive a Lego SPIKE from a Raspberry Pi.
